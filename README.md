# 🏠 Home Monsters — игра-тест на память

Интерактивная Memory-игра с 10 уникальными персонажами — домашними монстрами.

## Описание

Memory-игра в стиле "найди пару" с авторскими персонажами. Каждый монстр олицетворяет проблему ремонта: Скрипун Полович (скрипящие полы), Плесень Плесеневич (грибок), Капалыч (протечки) и другие.

После игры — тест на знание ремонта и звание: от "Паркетного философа" до "Бетонного бригадира".

## Технологии

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

## Установка

```bash
bun install
bun run dev
```

## Структура

- `/src/app/page.tsx` — главная страница
- `/src/app/game/page.tsx` — игра Memory
- `/src/app/monster/page.tsx` — страница монстра с викториной
- `/src/app/result/page.tsx` — результаты и звания
